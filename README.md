# idm-bypasser
Tired of the "The main IDM executive is corrupted." notification on your IDM? IDM Bypasser is here to fix it!
----
Inside the repo -- you will find a single .ahk file, an optional shortcut which you can delete, and a readme.txt!

# Needed in order to run
In order to run this you need AutoHotkey v2 installed.

# How to use?
In order for this to work, IDM must be saying "The main IDM executive is corrupted." or so and only it will only work in English if you won't even budge the .ahk file. (You can edit the .ahk for any language!) 
When you launch either the shortcut or the .ahk, it will automatically click the Continue downloading, bypassing the timer.
